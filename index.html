4-Stage Pipeline Architecture
Architecture

Git tracks snapshots through four distinct states. Notice that git fetch updates local tracking branches before merging.

STAGE 1
Working Tree
STAGE 2
Staging (Index)
STAGE 3
Local (HEAD)
STAGE 4
Remote Repo
Lifecycle Flow 
git add <file>              # Stage 1 -> Stage 2
git commit -m "feat:..."    # Stage 2 -> Stage 3
git push origin main        # Stage 3 -> Stage 4
git fetch origin            # Stage 4 -> origin/main
git pull --rebase           # fetch + rebase into Stage 1
Modern Branch Management
Branching

Modern Git uses git switch to navigate branches, completely retiring ambiguous git checkout branch syntax.

Switch & Create 
git switch <branch>         # Switch to branch
git switch -c <new-branch>  # Create and switch (-c = create)
git switch -                # Switch to previous branch
git branch -vv              # List branches with tracking state
git branch -d <branch>      # Safely delete merged branch
TaskModern (Git 2.23+)Legacy
Switch branch git switch <br> Clean git checkout <br>
Create & switch git switch -c <br> Clear git checkout -b <br>
File Restoration & Un-staging
Undo & Recovery

git restore replaces legacy checkout for files. Clearly separates working tree edits from index changes.

Discard & Unstage 
git restore <file>          # Discard unstaged working edits
git restore .               # Discard all unstaged modifications
git restore --staged <file> # Unstage file (keeps local edits)
git restore -s HEAD~1 <f>   # Restore file from previous commit
TaskModern (Git 2.23+)Legacy
Discard file edits git restore <f> git checkout -- <f>
Unstage changes git restore --staged <f> git reset HEAD <f>
Precision Staging & Diffing
Daily Workflow

Differentiate between unstaged file edits and changes already locked into the index ready for commit.

Interactive Staging & Diff 
git status -sb              # Short status + branch sync
git diff                    # Diff: Working tree vs Index
git diff --staged           # Diff: Index vs HEAD (Essential!)
git add -p                  # Interactively stage discrete hunks
git commit -m "feat:..."    # Commit staged snapshot
Tip: Always run git diff --staged before committing to review exactly what will enter history.
Merge Conflict Playbook
Troubleshooting

Step-by-step resolution when two branches alter identical lines:

Conflict Resolution Cycle 
git status                  # Identify conflicting files (UU)
# Edit files: resolve <<<<<<< HEAD vs >>>>>>> branch
git add <resolved-file>     # Mark conflict as resolved
git merge --continue        # Conclude the merge commit
git merge --abort           # Bail out and restore pre-merge state
Never leave conflict markers (<<<<<<<, =======, >>>>>>>) in your code.
Interactive Rebase & Squash
Branching & Rebase

Polish local commit history before opening a Pull Request:

Interactive Rebase 
git rebase -i HEAD~3        # Clean up last 3 local commits

# In editor commands:
# pick   = keep commit as is
# squash = combine into previous commit & merge message
# fixup  = combine into previous commit & discard message
# reword = keep commit but edit message

git rebase --continue       # Continue after edits/conflicts
git rebase --abort          # Cancel rebase entirely
Stashing Workbench
Undo & Recovery

Temporarily stash uncommitted work to switch contexts without making premature commits.

Stash Commands 
git stash push -m "WIP: ..."# Stash tracked edits with label
git stash push -u -m "..."  # Stash including untracked files
git stash list              # View saved stash stack
git stash pop               # Restore latest and remove from stack
git stash apply stash@{1}   # Restore specific stash, keep on stack
git stash drop stash@{0}    # Delete specific stash
Reset, Revert & Amend
Undo & Recovery

Choose the exact undo level based on whether the commits are local or shared publicly.

Undo Matrix 
git commit --amend          # Modify latest commit message/staged
git revert <commit>         # Safe public undo (creates inverse commit)
git reset --soft HEAD~1     # Rewind commit; keep changes staged
git reset --mixed HEAD~1    # Rewind commit; keep changes unstaged
git reset --hard HEAD~1     # Destructive: discard commit & all changes!
Rule: Never reset --hard on shared branches like main!
Detached HEAD Recovery
Troubleshooting

Occurs when you checkout a specific commit rather than a branch pointer.

Diagnostic & Escape 
# You are in detached HEAD if:
git status # says "HEAD detached at <hash>"

# Option 1: Discard experiment and return:
git switch main             # Return to main branch

# Option 2: Save commits made while detached:
git switch -c recovery-branch # Creates branch pointing here!
Git Worktrees (Parallel Folders)
Pro Workflows

Check out multiple branches simultaneously into separate directories without re-cloning or stashing.

Worktree Commands 
# Create separate folder for hotfix branch
git worktree add ../hotfix-folder hotfix-branch

# Work in both directories simultaneously
git worktree list           # View active worktree locations
git worktree remove ../hotfix-folder # Clean up when done
Remote Operations & Sync
Daily Workflow

Collaborate safely with upstream remotes without creating messy merge bubbles.

Remote Commands 
git remote add origin <url> # Register remote upstream
git push -u origin main     # First push: sets upstream tracking
git push                    # Routine push to tracked upstream
git fetch --prune origin    # Fetch and remove stale deleted branches
git pull --rebase origin main # Pull upstream linearly without merge commits
